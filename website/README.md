# Smartconnect – compacte website

Statische one-page website (HTML + CSS, geen build nodig). Open `index.html` in een browser of zet de map op een host naar keuze (Netlify, GitHub Pages, een gewone webserver).

Secties: hero · kenmerken · oplossing · kanalen · werkwijze · sectoren · contact.

Inhoud gebaseerd op de huidige smartconnect.eu (vertaald naar het Nederlands). Controleer klantnamen en teksten vóór livegang.
